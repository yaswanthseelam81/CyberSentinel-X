# CyberSentinel X

CyberSentinel X is an explainable security operations and threat detection platform.

## Project Goals

- Collect security events
- Detect suspicious behavior
- Correlate related events
- Calculate risk
- Map threats to MITRE ATT&CK
- Assist security investigations
- Generate incident reports
